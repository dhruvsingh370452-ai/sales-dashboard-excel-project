
# Sales Dashboard 2025 — Excel Project

## Overview
Built an interactive sales dashboard analyzing 140+ transaction records across 4 regions and 4 product categories, as part of my Data Analytics learning journey.

## Tools Used
Microsoft Excel — PivotTables, PivotCharts, Data Cleaning, KPI Cards

## Live Dashboard
[View the Live Excel Dashboard](https://1drv.ms/x/c/0373edf2ada82e83/IQBA8SFSBM3BTaQwo2fmbcHMAfDIhQDMSr8s71TgCgiQUOc?e=vnJBlo)

## What I Did
- Cleaned raw sales data (removed duplicates, fixed inconsistent text, handled missing values)
- Built PivotTables to summarize sales by Region, Product, Month, and Salesperson
- Created Bar, Line, and Pie charts to visualize key trends
- Designed KPI cards showing Total Sales, Best Month, Top Region, and Top Product

## Key Insights
- East region generated the highest total revenue
- August 2025 was the best-performing month
- Laptops contributed approximately 48% of total sales
- Priya Singh was the top-performing salesperson
